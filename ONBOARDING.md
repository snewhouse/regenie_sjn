## 1. 10-minute orientation

**What it is.** regenie is a C++ command-line tool for genome-wide association studies (GWAS) on large biobank cohorts. Step 1 fits a whole-genome ridge regression null model and writes leave-one-chromosome-out (LOCO) predictions. Step 2 uses those predictions to test variants and genes for association. This repo is a private fork that mirrors upstream rgcgithub/regenie exactly (no fork-only commits; git log).

**Tech.** C++11 with OpenMP, vendored Eigen 3.4.0, cxxopts, pgenlib, plus Fortran numeric libraries; the external BGEN library v1.1.7 is required. It builds with GNU Make or CMake, and has Docker images (plain, MKL, OpenBLAS). It needs g++ with C++17 support (for the remeta library), gfortran, cmake and zlib.

**Run it.**

```bash
# once: build the BGEN library outside the repo (needs network)
wget -O bgen.tgz http://code.enkre.net/bgen/tarball/release/v1.1.7
tar -xzf bgen.tgz && (cd v1.1.7 && python3 waf configure && python3 waf)

make BGEN_PATH=$PWD/v1.1.7 HAS_BOOST_IOSTREAM=0   # builds ./regenie
./regenie --help && ./regenie --version           # smoke test (all that CI runs)
bash test/test_bash.sh --path .                    # end-to-end tests on example/
```

**Layout (top level).**
- `src/` — all first-party C++, flat (`src/Regenie.cpp` holds `main`)
- `external_libs/` — vendored third-party code; do not edit
- `test/` — bash end-to-end test scripts
- `example/` — small fixture datasets
- `docs/docs/` — user docs (mkdocs source); `docs/site/` is generated and committed
- `scripts/` — R helpers and Docker helper script
- `.github/workflows/` — build smoke test and Docker publish

## 3. Architecture & data flow

A **monolithic batch pipeline**: one binary, one `main` (`src/Regenie.cpp:60`). Options are parsed into one `struct param` (`src/Regenie.hpp:181`), and one `class Data` (`src/Data.hpp:30`) owns all run state. `Data::run` dispatches on the step (`src/Data.cpp:87-91`):

- **Step 1** (`src/Data.cpp:95`): read genotypes and phenotypes, then level-0 ridge per block (`src/Step1_Models.cpp:462`), then level-1 stacking by trait type, then write `_pred.list` + `.loco` (`src/Data.cpp:968`).
- **Step 2** (`src/Data.cpp:135`): read the step-1 predictions, then loop per chromosome and block, run per-SNP score tests with Firth/SPA in an OpenMP loop (`src/Data.cpp:2476`), and write `.regenie` files (`src/Data.cpp:2012`). Gene-based tests go through masks, SKAT/ACAT and joint tests (`src/Data.cpp:2629`).

No database, no network; everything is files in, files out. No generated diagram (codemem has no C++ parser); an include-graph mermaid sketch is in the deep-dive. ⟶ `.claude/onboarding/02-architecture.md`

**0. Before you touch anything**
- Read `README.md`, `docs/docs/overview.md` and `docs/docs/options.md` (the user contract).

**1. Sync and branch**
- This fork has no upstream remote. Add one first: `git remote add upstream https://github.com/rgcgithub/regenie.git && git fetch upstream`.
- Branch from `master` (trunk-based). No naming rule is observed; use a descriptive fix/... or feat/... name.

**2. Make the change, following the conventions**
- Match the style of the file you are editing (§8). Imitate `src/Pheno.cpp` for core code.

- Anything touching the param struct, the Data class, the readers in `src/Geno.cpp` or the output formatters affects every test path.
- Find callers structurally: `ast-grep run -p 'compute_score($$$)' -l cpp src/` (codemem and PROJECT_INDEX do not index C++).
- Check whether output columns change. Downstream users parse the `.regenie` format.

**4. Test**
- Run `bash test/test_bash.sh --path .` and require "SUCCESS".
- Also build with *both* Make and CMake, since CI uses CMake (`.github/workflows/test.yml:67-70`).
- If you change a feature with no test (time-to-event, multi-trait, ordinal), add a scenario to `test/test_bash.sh` using `example/` data, and mirror it in `test/test_docker.sh`.

**5. Commit**
- Upstream uses short free-form messages, e.g. "Makefiles: make FC default to gfortran again" (git log).

**6. Open the PR (upstream)**
- Open it against rgcgithub/regenie `master` from your fork.
